Installation Steps — Chrome / Edge / Brave

1

Download the ZIP

Click the button above to download the extension ZIP file, then extract it somewhere on your computer.

2

Open Extensions Page

In Chrome go to chrome://extensions, in Edge go to edge://extensions, in Brave go to brave://extensions.

3

Enable Developer Mode

Toggle on Developer mode in the top right corner of the extensions page.

4

Load Unpacked

Click Load unpacked and select the extracted folder from Step 1.

5

Done!

The extension is now installed. Head back to nowfar.lol and enjoy more sources.

Note: This extension is open source. It unlocks additional streaming servers that aren't available by default. You may see a browser warning when installing — this is normal for extensions loaded outside the Chrome Web Store.
